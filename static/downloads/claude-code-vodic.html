Što je Claude Code (i zašto vas treba zanimati?)

Claude Code je AI asistent za kodiranje koji živi u terminalnom prozoru vašeg računala. Zamislite ga kao programera dostupnog 24/7 — s kojim razgovarate na razumljivom, svakodnevnom jeziku.


Evo što ga čini posebnim: Vi opišete što želite. Claude Code to izgradi. Nije potrebno predznanje kodiranja. Umjesto da razmišljate o "kodu", zamijenite tu riječ s "rješenjem". Claude Code je tehnički izvršitelj koji za vas stvara rješenja.

ŠTO CLAUDE CODE MOŽE UČINITI ZA VAS
Izgraditi funkcionalne web aplikacije i alate iz jedne rečenice
Automatizirati jednokratne ili ponavljajuće zadatke
Kreirati desktop aplikacije koje možete otvoriti dvoklikom
Pretvoriti vaše ideje u funkcionalne prototipe u minutama
ZA KOGA JE OVAJ VODIČ

Poslovni profesionalci, poduzetnici i radoznali umovi koji su početnici i žele koristiti AI za izgradnju stvarnih rješenja bez pisanja ijedne linije koda. Ovaj vodič je za ljude koji govore sebi:


"Kad bih samo imao alat koji bi mogao..." ili "Bilo bi sjajno kad bi se moglo samo..." — odmah zapišite te ideje jer ih danas možda i ostvarite.

PROVJERA STVARNOSTI — 2026. JE VEĆ OVDJE

Netko je izgradio vlastitu aplikaciju, s punom integracijom Notion i Slack alata, za svega 3,5 sata. Ljudi na internetu već stvaraju funkcionalne kopije softvera vrijednih milijardu eura. Izgradnja rješenja u 2026. neće nalikovati na 2024.

POGLAVLJE 02

Postavljanje za 60 sekundi

Ne trebate biti tehnički stručnjak. Samo slijedite korake.

macOS

KORAK
01

OTVORITE TERMINAL

Pritisnite Command + Space (Spotlight). Upišite "Terminal" i pritisnite Enter. Pojavit će se prozor — ne bojte se, samo ćete zalijepiti jednu liniju.

KORAK
02

ZALIJEPITE NAREDBU ZA INSTALACIJU

Kopirajte cijelu ovu liniju i zalijepite je u Terminal:

curl -fsSL https://claude.ai/install.sh | bash
KORAK
03

POKRENITE CLAUDE CODE

Nakon instalacije, upišite ovu jednu riječ iza znaka % pa pritisnite Enter:

claude
KORAK
04

PRIJAVITE SE

Otvorit će se prozor preglednika. Prijavite se s Claude Pro (20 EUR/mj) ili Claude Max (200 EUR/mj) računom. Gotovo.

Windows

KORAK
01

OTVORITE POWERSHELL

Pritisnite Windows + X i odaberite "Windows PowerShell" ili "Terminal". Alternativno, pretražite "PowerShell" u izborniku Start.

KORAK
02

INSTALIRAJTE NODE.JS (preduvjet)

Claude Code zahtijeva Node.js. Preuzmite s nodejs.org i instalirajte. Zatim provjerite: node --version

KORAK
03

INSTALIRAJTE CLAUDE CODE

U PowerShellu unesite:

npm install -g @anthropic-ai/claude-code
KORAK
04

POKRENITE I PRIJAVITE SE

Upišite "claude" i pritisnite Enter. Pratite upute za prijavu u pregledniku.

Vaša prva naredba: Izgradite nešto stvarno

Sada počinje zabava. Zamolite Claude Code da vam izgradi pravu desktop aplikaciju. Možete koristiti i glasovni unos!

ŠTO UPISATI
PROMPT: "Napravi mi jednostavnu [opišite svoju ideju]. Zapakiraj je kao macOS/Windows/Linux aplikaciju koju mogu dvaput kliknuti s radne površine — ne želim koristiti terminal. Objasni mi što radiš dok gradiš, na razumljivom jeziku. Evo što želim da radi: [opišite što želite]"
PRIMJER 1
"Napravi mi kalkulator troškova sastanka. Zapakiraj ga kao macOS/Windows/Linux aplikaciju. Objasni mi što radiš. Evo što želim: (1) Unesem koliko je ljudi na sastanku i prosječna plaća, (2) Prikazuje se iznos koji raste dok sastanak traje, (3) Postoji dugme 'Završi sastanak' koje prikazuje ukupni trošak, (4) Ako sastanak prijeđe 5.000 EUR, automatski se šalje e-mail HR-u s popisom sudionika."
PRIMJER 2
"Napravi mi osobni CRM za umrežavanje. Zapakiraj ga kao macOS/Windows/Linux aplikaciju. Objasni mi što radiš. Evo što želim: (1) Mogu dodavati ljude koje sam upoznao/la s bilješkama o tome gdje i o čemu smo razgovarali, (2) Podsjeća me ako nisam kontaktirao/la nekoga 30 dana, (3) Automatski sastavlja prijedlog poruke za kontaktiranje, (4) Mogu pretraživati po tvrtki, imenu ili ključnim riječima, (5) Još jedna korisna funkcija po tvom izboru."

5 moćnih stvari koje možete tražiti

Claude Code nije samo za izgradnju aplikacija. Evo pet kategorija zadataka koji odmah štede sate rada.

01 · AUTOMATIZIRANI EXCEL I CSV IZVJEŠTAJI
Prompt: "Imam 12 Excel datoteka u mapi Downloads, svaka ima list 'Prodaja'. Spoji ih u jedan zbirni izvještaj, izračunaj ukupne iznose po regiji i generiraj PDF s grafikonom."
02 · PRIKUPLJANJE PODATAKA S WEBA
Prompt: "Prikupi sve oglase za posao s [stranica] koji sadrže riječ 'menadžer', spremi u Excel s kolonama: naziv, tvrtka, datum objave, link."
03 · AUTOMATSKI EMAILOVI I OBAVIJESTI
Prompt: "Napravi skriptu koja svaki ponedjeljak ujutro pošalje email mom timu s popisom zadataka iz Excela. Uključi samo zadatke koji su 'U tijeku' ili 'Kasni'."
04 · OBRADA DOKUMENATA I PDF-OVA
Prompt: "Imam mapu s 50 PDF ugovora. Izvuci iz svakog: ime klijenta, datum potpisa, ukupnu vrijednost ugovora. Spremi sve u jedan Excel."
05 · OSOBNI ALATI I MINI APLIKACIJE
Prompt: "Napravi mi jednostavnu desktop aplikaciju za praćenje vremena — kliknem Start/Stop za svaki projekt, na kraju dana prikaže koliko sam sati proveo/la na čemu."

POGLAVLJE 05

Pro savjeti za bolje rezultate

BUDITE KONKRETNI, NE OPŠIRNI
❌ Loše:
"Napravi mi nešto za praćenje projekata"
✓ Dobro:
"Napravi Excel tablicu s kolonama: projekt, rok, status, osoba odgovorna. Dodaj dropdown za status: Nije počelo / U tijeku / Završeno / Kasni."
KORISTITE CLAUDE.MD ZA PAMĆENJE KONTEKSTA

Napravite tekstualni fajl CLAUDE.md u mapi projekta. U njega napišite kontekst:

Ovo je projekt za HR odjel tvrtke XYZ.
Koristimo Excel 2019, Windows 10.
Svi nazivi stupaca moraju biti na hrvatskom.
Email reporti idu na: tim@tvrtka.hr

Claude Code automatski čita taj fajl i pamti kontekst kroz cijelu sesiju.

KAD NEŠTO NE RADI — OPIŠITE GREŠKU
Prompt za debugiranje: "Kada pokrenem skriptu dobivam ovu grešku: [kopirajte tekst greške]. Radim na Windows 10, Python 3.11. Što je problem i kako ga riješiti?"
ITERIRAJTE MALIM KORACIMA

Ne tražite sve odjednom. Gradite korak po korak:

Korak 1: "Napravi osnovnu tablicu s 3 kolone"
Korak 2: "Dodaj automatski izračun ukupnog iznosa"
Korak 3: "Dodaj filter po datumu i izvoz u PDF"

SPREMITE DOBRE PROMPTOVE

Kad prompt dobro funkcionira, kopirajte ga u Word dokument ili Notepad. Idući put uštedit ćete 10 minuta pokušaja. Ovo je vaša osobna prompt biblioteka.

POGLAVLJE 06

Napredni savjeti: podignite razinu

GIT — SIGURNOSNA KOPIJA PROJEKATA

Git je sustav koji pamti svaku verziju vašeg projekta — kao "Undo" koji seže godinama unazad. Zamolite Claude Code da ga postavi:

"Postavi Git za ovaj projekt i napravi prvu sigurnosnu kopiju na GitHub-u."
RAD S VIŠE DATOTEKA ODJEDNOM
Prompt: "U mapi /Documents/Ugovori/ imam 200 Word dokumenata. Pronađi sve koji sadrže frazu 'raskid ugovora' i napravi Excel popis s nazivom fajla i datumom izmjene."
DEPLOYMENT — OBJAVA NA WEB

Kad izgradite web alat, Claude Code ga može odmah objaviti online besplatno:

"Objavi ovu web aplikaciju na Netlify ili Vercel. Besplatni plan je dovoljan. Daj mi link koji mogu podijeliti s kolegama."
INTEGRACIJA S NOTIONOM I SLACKOM
Prompt: "Svaki put kad u Notion bazi podataka promijenim status zadatka u 'Završeno', pošalji poruku u Slack kanal #tim-izvještaji s imenom zadatka i datumom."
SLJEDEĆI KORAK

Automatizirajte jedan zadatak ovaj tjedan.

Identificirajte jedan ponavljajući zadatak koji radite ručno — izvještaj, kopiranje podataka, slanje emailova. Opišite ga Claude Codeu što konkretnije možete. Rezultat: sati vraćeni nazad vama.
